# Documentación

`V12.1-reference/` conserva la documentación y evidencias de la baseline. Sus rutas y nombres históricos describen V12.1 y no deben tratarse como instrucciones de despliegue V2 sin revisión. Las decisiones nuevas se registran en `Specs/`.

Los archivos `increment-*.md`, `v2-validation-and-traceability.md`, `quality-test-inventory.md` y `e2e-failure-classification.md` también son informes históricos de incrementos anteriores. Sus referencias a Supervisor, turnos, rutas y pruebas eliminadas no describen el runtime actual. El contrato vigente está en `Specs/00-system-overview.md` a `Specs/05-payments-and-receipts.md` y en las pruebas actuales del repositorio.
