# Infraestructura

Mapa documental de V12.1 para preparar V2. Compose (`compose*.yaml`) permanece en la raíz porque sus contextos de build son relativos a ella. Dockerfiles, `vercel.json` y configuraciones de cada aplicación permanecen junto al componente. Antes de desplegar V2 habrá que revisar rutas, variables y configuración de Docker, Vercel, Render, Neon y Redis. No se cambió ningún despliegue actual.
